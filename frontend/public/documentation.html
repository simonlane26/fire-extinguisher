CSV Import Guide

Import multiple fire extinguishers at once using a CSV (Comma-Separated Values) file.

Required CSV Format

Your CSV file must include the following columns in this exact order:

Column Required Description Example
Location ✓ Yes Specific location of the extinguisher Kitchen, Hallway Floor 2
Building ✓ Yes Building name or identifier Main Building, Warehouse A
Type ✓ Yes Type of fire extinguisher Water, CO2, Foam, Powder
Serial Number No Manufacturer serial number SN12345
Last Inspection Date No Date format: YYYY-MM-DD 2025-01-15
Next Inspection Date No Date format: YYYY-MM-DD 2025-07-15
Status No Defaults to "active" if not provided active, maintenance
Notes No Additional information Near stove, Needs bracket

Example CSV File

Location,Building,Type,Serial Number,Last Inspection Date,Next Inspection Date,Status,Notes
Kitchen,Main Building,CO2,SN12345,2025-01-10,2025-07-10,active,Near the stove
Hallway Floor 2,Main Building,Water,SN67890,2025-01-15,2025-07-15,active,
Warehouse,Storage Building,Powder,SN11111,,,active,Needs replacement bracket
Reception,Main Building,Foam,SN22222,2025-01-05,2025-07-05,active,Behind front desk

Creating Your CSV File

Using Excel or Google Sheets:

  1. Create a new spreadsheet
  2. Add the column headers in the first row (exactly as shown above)
  3. Fill in your extinguisher data in the rows below
  4. Save as CSV: File → Save As → CSV (Comma delimited)

Important Notes

  • First row must be headers - The system will skip the first row automatically
  • Minimum required columns: Location, Building, and Type (first 3 columns)
  • Date format: Must be YYYY-MM-DD (e.g., 2025-01-15)
  • Empty optional fields: You can leave optional fields blank
  • Special characters: If a field contains commas or quotes, wrap it in double quotes
  • Maximum file size: 5MB per CSV file

⚠️ Common Mistakes to Avoid:

  • Missing the header row
  • Wrong date format (use YYYY-MM-DD, not DD/MM/YYYY)
  • Columns in wrong order
  • Missing required fields (Location, Building, Type)

How to Import

  1. Navigate to the Stock page
  2. Click the Import CSV button
  3. Select your prepared CSV file
  4. Click Upload
  5. Review the import results showing successes and any errors

✓ Pro Tip: Export your existing data first to see the exact format. You can then use this as a template for importing new data!

QR Code Management

Generate and manage QR codes for your fire extinguishers.

Generating QR Codes

  • Individual QR Code: View any extinguisher and click "Generate QR Code"
  • Bulk Generation: Navigate to QR Codes page and select "Generate from Extinguishers"
  • Building Filter: Filter by building to generate QR codes for specific locations

Public QR Code Scanning

QR codes can be scanned by anyone to view extinguisher information without logging in:

  • Location and building information
  • Type and serial number
  • Last inspection date
  • Next inspection due date
  • Current status

Printing QR Codes

  1. Generate QR codes (individual or bulk)
  2. Use your browser's print function (Ctrl+P or Cmd+P)
  3. Recommended: Print on waterproof labels or laminate
  4. Attach near each fire extinguisher

Inspection Tracking

Track and manage fire extinguisher inspections to maintain compliance.

Recording an Inspection

  1. Navigate to the extinguisher you want to inspect
  2. Click Record Inspection
  3. Fill in inspection details:
    • Inspection date
    • Condition assessment
    • Pressure reading (if applicable)
    • Any issues found
    • Notes
  4. Optional: Add photos of the extinguisher
  5. Click Save Inspection

Inspection Schedule

Fire extinguishers typically require:

  • Monthly visual inspections: Quick check for damage, accessibility
  • Annual maintenance: Thorough inspection by qualified person
  • 5-year internal examination: Detailed inspection (type-dependent)
  • Hydrostatic testing: Pressure testing (varies by type, typically 5-12 years)

💡 Automated Reminders: The system automatically calculates next inspection dates and sends email notifications when inspections are due.

Viewing Inspection History

  • Click on any extinguisher to view full inspection history
  • Filter by date range
  • Export inspection records to PDF or CSV

Generating Reports

Create comprehensive reports for compliance and record-keeping.

Available Reports

  • Inventory Report: Complete list of all extinguishers
  • Inspection Report: Detailed inspection history
  • Compliance Report: Overview of inspection status and upcoming due dates
  • Site Report: Building-specific reports

Report Formats

  • PDF: Professional formatted reports for printing or sharing
  • CSV: Spreadsheet format for further analysis

Generating a Report

  1. Navigate to the Reports page
  2. Select report type
  3. Choose date range (if applicable)
  4. Apply filters (building, type, status)
  5. Click Generate Report
  6. Download or print the report
