FIRE EXTINGUISHER CSV IMPORT GUIDE
==================================

This guide explains how to use the CSV import template to bulk import fire extinguishers into Firexcheck.

TEMPLATE FILE
-------------
Download: extinguisher-import-template.csv

REQUIRED FIELDS
---------------
- location: Physical location of extinguisher (e.g., "Reception Desk", "Kitchen Area")
- building: Building name (e.g., "Main Building", "Warehouse")
- type: Extinguisher type (Water, Foam, CO2, Dry Powder, Wet Chemical, etc.)
- status: Must be "Active" or "Out of Service"
- condition: Must be one of: "Excellent", "Good", "Fair", "Needs Attention", "Out of Service"

OPTIONAL FIELDS
---------------
- floor: Floor location (e.g., "Ground Floor", "1st Floor", "Basement")
- capacity: Extinguisher capacity (e.g., "2KG", "6L", "9KG")
- manufacturer: Manufacturer name
- model: Model number/name
- serialNumber: Unique serial number
- installDate: Installation date (format: YYYY-MM-DD)
- expiryDate: Expiry date (format: YYYY-MM-DD)
- lastInspection: Last inspection date (format: YYYY-MM-DD)
- nextInspection: Next inspection due date (format: YYYY-MM-DD)
- lastMaintenance: Last maintenance date (format: YYYY-MM-DD)
- nextMaintenance: Next maintenance due date (format: YYYY-MM-DD)
- serviceType: Type of service (e.g., "Annual Service", "6 Month Check")
- inspector: Inspector name
- notes: Additional notes or comments

DATE FORMAT
-----------
All dates must be in format: YYYY-MM-DD
Examples: 2024-01-15, 2025-06-30, 2023-12-01

COMMON EXTINGUISHER TYPES
--------------------------
- Water
- Foam
- CO2
- Dry Powder
- Dry Powder D Class
- Wet Chemical
- Fire Blanket
- Aqua Spray
- Lithium
- P50 Foam
- P50 Powder
- P50 Water Mist

CAPACITY EXAMPLES
-----------------
- 1KG, 2KG, 3KG, 4KG, 5KG, 6KG, 9KG (for powder/CO2)
- 2LTR, 3LTR, 6LTR, 9LTR (for water/foam)

TIPS
----
1. Do NOT delete the header row (first row with column names)
2. Delete the example rows and add your own data
3. Use double quotes around text that contains commas
4. Leave optional fields blank if you don't have the data
5. Dates can be left blank and filled in later
6. Ensure status is exactly "Active" or "Out of Service" (case-sensitive)
7. Save the file as CSV (Comma Separated Values) format

EXAMPLE ROWS
------------
The template includes 4 example rows showing different extinguisher types.
Replace these with your actual extinguisher data.

IMPORTING
---------
1. Download the template
2. Fill in your extinguisher data
3. Save as CSV file
4. Use the Import function in Firexcheck
5. Select your CSV file
6. Review and confirm the import

TROUBLESHOOTING
---------------
- Check that dates are in YYYY-MM-DD format
- Verify status is "Active" or "Out of Service"
- Ensure condition matches one of the 5 allowed values
- Check for special characters that might break CSV format
- Make sure commas in text fields are within quotes
